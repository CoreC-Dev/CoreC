## 评分依据

### 测试覆盖（40%）
- 10 = 覆盖率 ≥85% 且关键路径有回归测试
- 8 = 覆盖率 ≥70%
- 6 = 覆盖率 ≥50%
- 4 = 覆盖率 ≥30%
- 2 = 覆盖率 <30%
- 数据来源：Phase 1 `go test -cover` 实测（整体 80.1%），逐包覆盖率见 `tech-debt-tracker.md` TEST 条目

### 文档完备（20%）
- 10 = 有包注释 + 文档无死链/孤儿 + 配置示例与代码一致
- 7 = 有文档但缺包注释或有孤儿文档
- 5 = 缺包注释 + 有过时内容
- 数据来源：DOC 扫描（18/27 缺包注释，2 孤儿文档，0 死链，DOC-001 配置示例误导）

### 复杂度控制（20%）
- 10 = 无超 400 行文件，gocyclo 全 <20，无 God Object
- 7 = 有 400–600 行文件或候选带函数
- 5 = 有 600–800 行文件或 gocyclo >20（nolint 抑制）
- 3 = 有 >800 行文件或多个 God Object
- 数据来源：CPLX 扫描（13 文件 >400 行，4 函数 gocyclo >20，7 God Object）

### 依赖合规（20%）
- 10 = 0 环 / 0 跨层 / 0 跨域（当前全项目达标）
- 扣分项：ARCH-002 config 单例耦合（config 域扣 3 分）
- 数据来源：ARCH 扫描
